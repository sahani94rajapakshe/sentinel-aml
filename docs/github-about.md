## About Section (Extended)

```
SentinelAML is an AI-powered financial crime investigation copilot built for fraud analysts and compliance teams.

The platform provides a production-oriented backend for AML investigations: customer and account lifecycle management, transaction monitoring foundations, and a Clean Architecture + CQRS codebase designed to scale into fraud scoring, case management, relationship analysis, and AI-assisted report generation.

Built with ASP.NET Core 9, PostgreSQL, Entity Framework Core, MediatR, and FluentValidation.

Current status: Core REST APIs and domain model implemented. JWT auth, transaction processing, and AI copilot on the roadmap.
```
