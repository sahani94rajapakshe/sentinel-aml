# SentinelAML

AI-Powered Financial Crime Investigation Copilot

## Overview

SentinelAML is a financial crime investigation platform designed to help fraud analysts investigate suspicious transactions.

The platform combines transaction monitoring, fraud risk scoring, investigation case management, relationship analysis, timeline reconstruction, and AI-powered investigation reports.

## Technology Stack

### Backend

* ASP.NET Core 9
* C#
* Entity Framework Core
* PostgreSQL

### Architecture

* Clean Architecture
* CQRS
